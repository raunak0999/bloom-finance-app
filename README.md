🌸 Bloom Finance App

Smart Personal Finance Management Powered by AI

Bloom Finance App is a modern full-stack personal finance management platform designed to help users take complete control of their financial life.
The application combines expense tracking, budgeting, investment monitoring, savings goal management, and AI-powered financial assistance into one seamless and user-friendly experience.

Whether you're managing daily expenses, planning long-term savings, or analyzing spending habits, Bloom Finance App provides intelligent tools and insights to help users make smarter financial decisions.

✨ Features
💰 Expense Tracking
Add, edit, and delete expenses
Categorize transactions (Food, Travel, Shopping, Bills, etc.)
Real-time expense summaries
Monthly and yearly spending analysis
📊 Budget Management
Create personalized budgets
Set category-wise spending limits
Track budget usage visually
Receive alerts when nearing limits
📈 Investment Monitoring
Track investments and portfolio growth
Monitor profits and losses
Visual performance analytics
Historical investment records
🎯 Savings Goals
